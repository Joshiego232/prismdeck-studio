# PrismDeck feature status

## Active in the editor

- Remembered-position snapping: previous move/resize bounds become additional alignment guides.
- Reusable custom-shape library with previews, search, folders, renaming, drag insertion and browser-local persistence.
- Improved Layers panel with collapsible group rows, additive/toggle selection and drag reordering.
- Group styling preserves each object's individual fill and gradient when styles differ.
- Master Slides & Theme Designer with reusable layouts and six theme presets.
- Smart Diagram Builder with editable process, timeline, hierarchy, cycle and mind-map diagrams.
- Advanced chart editing and CSV/tab-separated data import.
- Expanded slide animation controls and internal slide-navigation actions.
- Contextual object toolbar, alignment/distribution tools, memoized rendering and improved autosave flushing.

## Still staged and inaccessible

- Bible verse insertion: provider contracts only; no translation source, verse search, insertion UI or multi-verse layout builder.

Do not enable `bibleVerseInserter` without explicit approval.
